# Depthcue

Working name. Planning stage: there is no code yet.

Depthcue is an open-source format and player for explanations that an agent can write, a human can repair, and both
can present together. A deck is a typed JSON source with stable ids, so it can be generated, reviewed in a pull
request, edited by hand, and read later as a document.

- [Plan](docs/PLAN.md): thesis, architecture, v0.1 scope, speed budgets, brand direction, early tests.
- [Research](docs/RESEARCH.md): survey of existing tools, user complaints and architecture findings, with sources.
